## 0. 字画 vs 字符（结论）

- 游戏文本 = 字节序列。每个字节 → 查 `charmap.txt` → 查字库图形（字模/glyph，像素图）。
- **已在字库里的字**（大写 A-Z、数字、假名全量、约 150 个汉字）→ 直接打字，preproc 自动转字节，字库有现成字模。
- **不在字库里的字**（小写 a-z、中文常用字）→ 必须**画字模（像素图）** + 加进 charmap + 字库。

| 语言 | 需画字模 | 说明 |
| --- | --- | --- |
| 日语 | 0 个 | 平假名/片假名全量 + 约150汉字 |
| 英文大写 | 0 个 | A-Z + 数字 + 标点全有 |
| 英文小写 | 26 个 | 需画 a-z |
| 中文 | 视文本而定 | 字库只有约150个日文汉字，缺常用简体字 |

## 1. 对话演出（本轮目标：跑通）

### 1.1 机制（已研究清楚，全是原生）

脚本流程（命令都在 `asm/scripts/commands.inc`）：

```
lock                          ← 锁角色（无法移动）
print_message msgtype textid  ← 弹对话框（调用 PrintTextWindow）
wait_msgbox_end               ← 等玩家按掉对话框
release                       ← 解锁角色
end
```

- 对话框：`PrintTextWindow(TextID, kind)`（`script_command.c:919` Cmd_message）。
- 头像（mugshot）：**嵌在文本里的控制码**，不是单独命令。

### 1.2 头像切换（mugshot）

- 控制码 `CHAR_MUGSHOT = 0xF3`（charmap 里的 `WINDOW`）。
- 文本中写 `0xF3` + 一个字节，字节 = `(头像编号 << 1) | 左右侧`。
- 头像编号索引 `gDialogGraphics` 表（`dialog.s`），现成头像约 57 个：

  Zero、Ciel、四天王（Harpuia/Leviathan/Fefnir/Phantom）、
  八斗将（Blazin/Childre/Hellbat/Deathtanz/Cubit/Glacierle/Volteel/Tretista）、
  X、Copy X、Weil、Omega、以及反抗军全员（Cerveau/Alouette/Andrew/…）。

- **头像切换 = 在对话文本里插入多个 `0xF3` 控制码**。多段对话时，每段开头用不同的头像字节即可实现头像随说话人切换。

### 1.3 我要做的

1. 把 0.7.5 的事件脚本从「黑屏」改成 `lock + 多段对话(带头像切换) + release + end`。
2. 文本：先验证「站定 → 弹框带头像 → 按掉 → 换头像 → 再弹 → 解锁」的完整流程。

### 1.4 需要你/Codex 定

- 第一段对话用**哪个角色头像**、说什么（语言：日 / 英大写 / 中文）。
- 是否要「两段对话 + 头像切换」的演示（推荐，能展示头像切换）。

## 3. 字画需求（美工，等文本内容确定后列清单）

### 3.1 什么时候需要

- 只有「字库里没有的字」需要画字模。
- 日语/英文大写：0 个，直接写。
- 中文：**等对话文本确定后**，我列「缺失字符清单」给你。

### 3.2 字模规格（初步）

- 尺寸：全角 16×16（2 个 8×8 块横排），半角 8×8。
- 格式：4bpp，16 色，用游戏字库调色板。
- 一个字符一个或多个块。

### 3.3 流程

1. 确定对话文本（语言 + 内容）。
2. 我列「缺失字符清单」（例如：你/我/是/了/有/说…）。
3. 你画字模。
4. 我加进 charmap + 字库 + 文本。
